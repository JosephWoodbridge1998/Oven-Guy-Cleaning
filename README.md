Open index.html in a browser. It is self-contained, with embedded CSS, original SVG artwork and a client-side mailto helper. No installation is required.

## Enquiry flow
The original site's backend is not migrated. The form prepares an email and requires the visitor to review and send it using their own email client. No server storage, automatic submission, live availability, payment or booking confirmation is provided. A production launch needs a genuine enquiry destination and appropriate privacy information if replacing this helper with a backend.
